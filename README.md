проверить работу роута

## РЕШЕНИЕ

Проект полностью контейнеризирован с помощью **Docker Compose**.

### Быстрый старт

**1.  Создать и настроить файл `.env`**

Создайте файл `.env` в корне проекта со следующими настройками:

```env
DB_USER=<имя_пользователя>
DB_PASS=<пароль>
DB_HOST=localhost
DB_PORT=5432
DB_NAME=ads_db
```

**2. Собрать образы**

```bash
docker-compose build
```

**3. Запустить контейнеры в фоновом режиме**

```bash
docker-compose up -d
```


**4. Проверить статус контейнеров**

```bash
docker-compose ps
```

*Оба контейнера (`ads_postgres` и `ads_web`) должны быть в статусе `Up`.*


**4. Тестирование API**

Рекомендуется использовать файл **`rest.http`** 


**5. Остановить, удалить контейнеры и очистить базу данных**
```bash
docker-compose down -v
```
