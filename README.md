# Домашнее задание к лекции «Celery»

Специалист по машинному обучению создал модель для
[апскейлинга](https://ru.wiktionary.org/wiki/%D0%B0%D0%BF%D1%81%D0%BA%D0%B5%D0%B9%D0%BB%D0%B8%D0%BD%D0%B3)
изображений и функцию, которую позволяет ее использовать.
Файлы проекта находится [здесь](upscale).
`EDSR_2.pb` - модель.
В модуле `upscale.py` находится функция `upscale`, которая имплементирует модель и функция `example` с примером использования.
В файле `requirements.txt` перечислены зависимости

Перед Вами стоит задача написать сервис для апскейлинга изображений на базе Flask, Celery и ИИ модели.
Должно быть реализовано 3 роута

- POST `/upscale`. Принимает файл с изображением и возвращает id задачи
- GET `/tasks/<task_id>` возвращает статус задачи и ссылку на обработанный файл, если задача выполнена
- GET `/processed/{file}` возвращает обработанный файл

Дополнительные задачи:

- перепишите функцию `upscale` так, чтобы файл `EDSR_x2.pb` считывался только один раз, а не при каждом вызове функции
- попробуйте написать сервис и функцию `upscale` таким образом, чтобы не сохранять файлы изображений на диск
- докеризируйте приложение
- напишите тесты

Результатом работы является рабочее API.

## Решение

**Шаг 1:  Запуск  Docker**

* Запустить Docker Desktop
* В корне проекта выполнить:

```bash
 docker-compose up --build
```

Приложение будет доступно по адресу http://127.0.0.1:5000

**Шаг 2: Работа с изображением**

1. Загрузить изображение

```bash
curl.exe -X POST http://127.0.0.1:5000/upscale -F "file=@.\upscale\lama_300px.png"
```

В ответе будет что-то вроде:

```bash
{"task_id": "b23d7183-dd53-4d11-b59f-0f5e3e1c5af4"}
```

**Скопировать этот **`task_id` и проверить статус:

1. Проверит статус (заменить TASK_ID на реальный ID)

```bash
curl.exe http://127.0.0.1:5000/tasks/b23d7183-dd53-4d11-b59f-0f5e3e1c5af4
```

**Подождать несколько секунд (нейросеть грузится), статус должен стать **`SUCCESS`:

```bash
{
  "task_id": "b23d7183-dd53-4d11-b59f-0f5e3e1c5af4",
  "status": "SUCCESS",
  "result_url": "http://127.0.0.1:5000/processed/lama_300px_processed.png"
}
```

Если статус "status": "PENDING", то повторить запрос:

```bash
curl.exe http://127.0.0.1:5000/tasks/b23d7183-dd53-4d11-b59f-0f5e3e1c5af4
```

Скачать результат:

3. Скачать обработанное изображение

```bash
curl.exe http://127.0.0.1:5000/tasks/b23d7183-dd53-4d11-b59f-0f5e3e1c5af4/result -o result.png
```

**Файл **`result.png` появится в текущей папке — это увеличенное изображение!

P.S.

В данном случае мы не используем requests.http потому что сталкиваемся с известным багом HTTP-клиентов (плагинов REST Client в VS Code) при работе с локальными файлами на Windows. Плагин просто не может корректно отобразить ответ и зависает.

**Шаг 3: Запуск тестов**

Останавливать работающий Docker (docker-compose up) не обязательно.

Эта команда создаст новый чистый контейнер на основе образа flask, запустит в нем тесты, покажет результат и автоматически удалит этот временный контейнер после завершения (благодаря флагу --rm).

Открыть новое окно PowerShell (в папке проекта) и выполнить:

```bash
docker-compose run --rm flask pytest -v
```

